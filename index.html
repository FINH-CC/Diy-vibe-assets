Working with this library

Pull the latest from GitHub

git archive origin/main -- src/app/ui-animations/9 | tar -x -C /tmp/pull
cp /tmp/pull/src/app/ui-animations/9/* interactions/src/pages/ui-animations/9/

Check interactions/README.md for fixes to re-apply.

Make changes

Edit interactions/src/pages/ui-animations/<N>/page.tsx. npm run dev to preview, npm run build to publish.

Duplicate an animation

Copy a numbered folder, add a <Route> in interactions/src/App.tsx, rebuild.

Expand the library

Add an entry to CLIPS in assets/items.js — the card and its link appear automatically.
