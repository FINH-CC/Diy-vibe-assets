Working with this library

Pull the latest from GitHub

Each animation's real source lives in alexisbardini/diyvibes on origin/main, under src/app/ui-animations/. Pull a fresh copy of any page without touching your local DIYVIBES checkout:

git archive origin/main -- src/app/ui-animations/9 | tar -x -C /tmp/pull
cp /tmp/pull/src/app/ui-animations/9/* interactions/src/pages/ui-animations/9/

Re-apply the same Next.js→Vite fixes noted at the top of interactions/README.md (plain <img> instead of next/image, etc.) if the file changed upstream.

Make changes

Edit any page under interactions/src/pages/ui-animations/<N>/page.tsx and its .module.css. Run npm run dev inside interactions/ to preview live, then npm run build to regenerate interactions/dist/ — that's what the dashboard cards link to.

Duplicate an animation

Copy a numbered folder (e.g. interactions/src/pages/ui-animations/9/ → .../18/), add a <Route> for it in interactions/src/App.tsx, then rebuild.

Expand the library

Add one entry to CLIPS in assets/items.js (file, title, desc, and the live route number) — the dashboard card and full-screen link are generated from that automatically.
